# BirdLock 1.11.0 更新说明

- **直接导入相机 RAW**。可优先使用机内预览，或选高分辨率解码。RAW 和相机直出的 JPEG 同时存在时，可优先保留其一或全部导入。
- **Mac 支持导入上级文件夹**。选择或拖入上级文件夹，即可读取它及各层子文件夹里的照片，再按拍摄时间识别连拍。
- **Mac 照片导入进度**。读取照片时显示已检查数量和预计剩余时间，可取消并重新选择文件夹。选择高分辨率 RAW 解码时，导入检查使用缩小的图像，工程仍保留原始解码尺寸。
- **较长的 SDR 视频**。单次最多 600 秒、18,000 帧，两项上限同时适用。开始抽帧前会检查缓存盘空间。
- **连拍和音轨更好编辑**。连拍组可重命名，可定位原片，可撤销和重做。独立音轨可单独启停。快门音效新增佳能 EOS-1D Mark II 高速连拍和 EOS R5 Mark II 的四段连拍录音。
- **平台体验**。Mac 首页可打开工程，Finder 可识别工程图标，导出页会记住上次选的目录。两端提供浅色、深色和跟随系统外观。Windows 改善便携包启动、缓存清理和原素材定位。
- **更新源**。可以选择更新源，完整包及清单仍按软件内置公钥验证。
- **导出更稳妥**。视频和 GIF 完成后才替换同名文件。图片序列遇到不可读画面时会提示失败；渲染或编码阶段取消会保留已有成品。Windows 也改善了导出初始化失败后的重试，以及缺少有效头部角度时的旋转表现。

## RAW 解码与相机兼容性

- **Mac** 使用 macOS 自带的 RAW 框架。ImageIO 读取机内嵌入预览，Core Image（CIRAWFilter）负责高分辨率解码。机型和压缩格式的支持取决于本机 macOS 版本。按系统版本查阅 Apple 的 RAW 兼容性列表：[macOS 14 Sonoma](https://support.apple.com/zh-cn/105094) · [macOS 15 Sequoia](https://support.apple.com/zh-cn/120534) · [macOS 26 Tahoe](https://support.apple.com/zh-cn/122870) · [macOS 27](https://support.apple.com/zh-cn/127493)。
- **Windows** 使用 BirdLock 随包提供的开源 LibRaw 0.22.2，通过 rawpy 0.28.0 读取机内嵌入预览和解码高分辨率 RAW。兼容性随 BirdLock 所附解码器版本更新。查阅 [LibRaw 0.22 支持的相机列表](https://www.libraw.org/supported-cameras)，并留意列表中的压缩格式与构建选项限制。

两端可尝试导入 ARW、NEF、NRW、CR2、CR3、RAF、DNG、RW2、ORF、PEF 和 SRW。相同扩展名也可能采用不同的压缩方式，请按机型和拍摄设置查表，再用一张原片试开。能显示机内预览时，高分辨率解码仍可能受限。部分 Nikon 高效率 NEF 在当前 Windows 版上不可读，可先试用同机拍摄的 JPEG。

工程仍引用原素材。跨设备打开时，请一并保留照片、视频和外部音频文件，需要时重新定位到它们所在的文件夹。
