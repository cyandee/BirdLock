# BirdLock 1.11.0 更新说明

本次新增相机 RAW 导入，放宽 SDR 视频时长上限，并改善连拍分组、音轨控制、工程打开和导出。在软件里在「帮助 → 本次更新说明…」随时查看本文。

## 导入 RAW，选择机内色彩或高分辨率

- **Mac** 点首页「选择文件夹…」或工具栏「导入」，在选择窗口下方选「RAW 优先使用机内预览」或「RAW 高分辨率解码」，再选照片或文件夹。
- **Windows** 导入前打开「文件 → RAW 渲染策略…」，选择「相机直出色彩（机内预览优先）」或「RAW 高分辨率解码」。再通过「导入连拍文件夹…」或「导入照片文件…」选素材。
- **机内预览**适合保留相机预设的色彩、快速预览。需要大幅裁切或输出高分辨率时，选高分辨率解码。同一 RAW 在这两种模式下的色彩和有效画幅可能不同。如果导出界面提示所用机内预览尺寸较小，可以关闭「以完整分辨率渲染」继续导出，或重新导入原片并选择高分辨率解码。
- **RAW 和 JPEG 配对**适用于同一目录下、同名且拍摄时间相符的照片。默认优先保留 JPEG。拍了 RAW + JPEG、想用 RAW 剪辑时选「优先 RAW」。想分别比较两份时选「两者都导入」。Mac 在导入窗口设置，Windows 在「文件 → RAW + JPEG 搭配导入…」设置。渲染策略和配对设置用于下一次导入，已保存工程继续使用它记录的 RAW 来源。

### RAW 解码与相机兼容性

- **Mac** 使用 macOS 自带的 RAW 框架。ImageIO 读取机内嵌入预览，Core Image（CIRAWFilter）负责高分辨率解码。机型和压缩格式的支持取决于本机 macOS 版本。请按本机版本查看 Apple 的机型与压缩格式清单。 [macOS 14 Sonoma](https://support.apple.com/zh-cn/105094) · [macOS 15 Sequoia](https://support.apple.com/zh-cn/120534) · [macOS 26 Tahoe](https://support.apple.com/zh-cn/122870) · [macOS 27](https://support.apple.com/zh-cn/127493)。
- **Windows** 通过 rawpy 0.28.0 调用随 BirdLock 提供的开源 LibRaw 0.22.2，读取机内嵌入预览和解码高分辨率 RAW。兼容性随 BirdLock 所附解码器版本更新。[LibRaw 0.22 支持的相机列表](https://www.libraw.org/supported-cameras)

两端可尝试导入 ARW、NEF、NRW、CR2、CR3、RAF、DNG、RW2、ORF、PEF 和 SRW。同一型号可能有多种 RAW 压缩格式，建议核对清单的格式限制，再用一张原片试开。部分 Nikon 高效率 NEF 在当前 Windows 版上不可读，可试用相机直出 JPEG 或转成 DNG。

## Mac 导入上级文件夹，并查看读取进度

1. 在首页点「选择文件夹…」，或把上级文件夹拖入窗口。例如选择「周末观鸟」，BirdLock 会寻找它及各层子文件夹中支持的照片，连拍按拍摄时间自动分组。
2. 扫描完成后，进度条会显示已检查张数、总数和预计剩余读取时间。高分辨率 RAW 的导入检查使用小尺寸解码，后续渲染仍可使用原始解码尺寸。照片读完后进入独立的识别分析阶段。
3. 选错目录或等候太久，可以点「取消并重新选择…」换一个照片较少的文件夹，也可以点「取消」结束读取。

这适合一次导入按日期或场次存放的多组照片，也方便在大批 RAW 导入前先试一组。

## 导入更长的 SDR 视频

1. 选择「文件 → 导入视频（实验）…」，或单独拖入一个 SDR MP4 / MOV。
2. 设置片段起点、时长和采样帧率，核对窗口显示的实际帧数和预计缓存占用。单次最多 **600 秒、18,000 帧**，两项上限同时适用。例如以 60 fps 采样时，18,000 帧约为 300 秒。空间不足时可缩短片段或降低采样帧率。
3. 点「导入并分析」。视频有可解码音轨时会自动加入「视频原声」。在右侧「画面 → 视频防抖」检查裁切与增稳，再预览并导出。

这让较长的拍摄片段也能使用主体锁定和防抖。需要处理 HDR 视频时，请先转换为 SDR。

## 整理连拍组、定位原片与撤销编辑

- **逐组查看或合成同一视频**。从顶部的连拍组选单切换。要拼接多个片段，Mac 选「合并选中组 → 同一视频」，Windows 在「输出 → 连拍与特写」选「选中组合为同一视频」。勾选需要的组，用上下箭头或「上移」「下移」排好播放顺序。
- **重命名和找原片**。Mac 进「输出 → 关键帧特写 → 连拍分组」，用铅笔和文件夹按钮。Windows 进「输出 → 连拍与特写」，用「重命名…」和「显示原片」。查找当前一张则用 Mac「显示 → 在访达中显示当前原片」或 Windows「文件 → 在文件资源管理器中显示当前原片」。
- **撤销和重做**。用「编辑」菜单中的「撤销」「重做」。Mac 快捷键为 ⌘Z / ⇧⌘Z，Windows 为 Ctrl+Z / Ctrl+Shift+Z，Windows 也可用 Ctrl+Y 重做。排除照片、修改组名或调整顺序后可以用这些命令回退并比较编辑结果。

## 单独启停音轨，选择佳能快门录音

- 在「输出 → 音效与多轨」找到目标轨的「启用音轨」。关掉它会将该轨从预览和导出的混音中移除，原有的音量、起点和淡入淡出设置会保留。对比有无快门声时，可以随时再开启该轨。
- 同一面板先选「相机」，再选「fps / 录音」，点「添加快门声」即可加入一条轨道。新增 **Canon EOS-1D Mark II 高速连拍**及 **Canon EOS R5 Mark II 四段连拍录音**。长短不同的连拍可分别选择合适的录音，加入后还可以单独调整快门声音轨的音量。

## 保存工程、跨设备继续编辑和清理缓存

- 编辑到一半时用「文件 → 保存工程…」。下次通过「文件 → 打开工程…」重新打开 `.birdlock` 文件，继续使用已保存的分组、识别结果、编辑和音轨设置。Mac 首页也有「打开工程…」，安装版在访达中以 BirdLock 图标显示工程，并可双击打开。
- 工程引用原照片、视频和外部音频等素材。跨设备移动时请把工程和素材一起保留，尽量沿用相对目录结构。遇到「重新定位素材」时，选原片所在的文件夹。
- 两端解码器可能为同一张 RAW 输出不同画幅。已有 Sony α1 II 无损 ARW 在 Windows 高分辨率模式下保存后，Mac 无法恢复该工程的实例。需要在两端继续编辑时，可先用一张原片验证。遇到这种情况，可以在原系统继续编辑或导出，或者在目标系统用原片重新导入。该样本使用机内预览保存的工程可以跨端打开。
- 磁盘空间紧张时，打开「文件 → 缓存管理…」清理未使用的过程文件。视频导出完成后，还可以选择「保存工程并清理」。以后打开同一工程时，只要保留原视频，软件会按已保存的采样和镜头设置重建过程文件。

## 选择外观和导出位置，导出出错时重试

- **外观**可在「显示 → 外观」选「浅色」「深色」或「跟随系统」。跟随系统时，BirdLock 会随系统日夜模式一起切换。
- **Mac 导出位置**在导出窗口中显示。打开「导出…」，选视频、图片序列或 GIF，点「选择位置并导出…」。确认后，窗口会立即显示所选文件夹，下次导出也会优先从该目录开始。
- **更稳妥的重试**。Mac 的视频和 GIF 完成后才替换同名文件。图片序列遇到无法读取的画面时会报错。渲染或编码途中点「取消导出」，等待取消完成后，可以调整设置再导出，已有成品会保留。Windows 也改善了导出初始化失败后在同一次运行中重试的流程。遇到报错先看提示，定位原片或调整编码后再试。
- **Windows 手动旋转**。部分照片缺少有效的鸟头角度时，成片仍应用你设置的手动旋转角度。

## Windows 便携版与更新源

- **Windows 便携版**可直接从解压后的文件夹运行。先把 ZIP 完整解压到可写文件夹，再打开其中的 `BirdLock.exe`。更换存放位置时可整体移动解压后的文件夹，让程序、运行库和资源一起移动。
- **选择更新源**。Mac 从 BirdLock 菜单打开「更新源…」。Windows 先打开「帮助 → 检查更新…」，再点窗口里的「更新源…」。可以上移常用源、添加或删除来源，也可以点「恢复默认」。例如 GitHub 访问不稳定时，可以把 BirdLock 镜像移到前面。软件仍会验证更新内容的签名和校验值。
