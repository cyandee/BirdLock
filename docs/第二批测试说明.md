# BirdLock 1.2.0 本地测试版

> 历史记录：本文只描述1.2.0交付时的功能和验证，不代表当前菜单或发布状态。当前为1.4.0源码，见[版本记录](迭代记录.md)、[使用说明](使用说明.md)和[验收清单](整批功能验收清单.md)。

本批在已通过用户稳定性试用的 1.1.0 基础上继续开发。仅本地交付，未推送 GitHub、发布 Release 或更改 Vercel；第一批安装包及基线保留，可回退。

## 已完成

1. 鸟眼、鸟头、鸟身分别配色，鸟身框单独调整大小；默认框住检测到的整只鸟及翅膀。
2. 快门闪烁边框可调颜色和大小，频率 1—120 次/秒。受视频采样限制，高频可能呈现为静止或较慢闪烁；建议用 3—10 次/秒先确认风格。
3. 内置索尼 10/20/60/120 fps 四档采样循环，使用上传的对应 WAV 片段重复，不变速。尼康 Z8 使用此次上传的原始 MP3 循环。保留素材说明与哈希；索尼解码仍是提供素材中的近似格式，听感需维护者试听。
4. 新增多条音频轨道，可以让背景音乐、快门和其他音效共存。独立静音、循环、音量、素材起点、视频起点、长度及淡入淡出；音频块可拖动调整视频起点。
5. 双平台预览与视频导出共用混音设置；音频缺失会提示。原单曲背景音乐及旧对焦框配置兼容。
6. 已更新使用说明、资源来源记录、维护记录；反馈入口为邮箱：cyanodee@gmail.com

## 请重点试用

1. 导入原来稳定的照片组，在「输出 → 对焦框」分别设三种颜色，单独缩放鸟身框，确认眼/头框大小不跟着改变。
2. 改变快门边框颜色及占画面大小，比较预览和导出；分别检查 6 次/秒和 120 次/秒设置能保存，理解高频受视频帧率限制。
3. 在「音效与多轨」添加索尼快门，切换四档，播放并试听；再添加尼康 Z8，确认原录音声音可辨认、循环接续是否合适。
4. 添加一首背景音乐，与快门声同时播放、导出；分别静音、调音量，设置不同视频起点与长度；拖动音频块。
5. 检查从素材非零时间开始、循环和不循环、淡入淡出、暂停后续播、删除音轨及关闭重开后的设置。
6. 在 Windows 切换三个设置页、缩放窗口，重复导入、播放、导出和关闭；尽可能在实体 x64 电脑与显卡上补测。

## 验证范围

- Swift：10 项自动测试，包括旧配置、独立配色、120 Hz、鸟身几何、多轨编排、缺失音频以及上传 MP3 + WAV 混音解码。
- Python：13 项自动测试，在 Mac 和 Windows 虚拟机均通过；检查实际 PCM 音量、各轨起点、静音、尾部静音、试听起点、循环周期、配色和边框实际像素。
- Mac：69 张真实照片导出，包含两条音频，验证 H.264、AAC、69 帧、2.3 秒；音视频结束相差小于一个采样点。通用架构、临时签名完整性、内置音效哈希及 DMG 校验通过。
- Windows 成品：内置五种声音的哈希自检、启动冒烟、12 张真实照片的 10 轮 / 80 次布局检查均通过；120 次/秒设置、音轨控件和双轨导出通过，H.264 720×1280 与 HEVC 1440×2560 均带 AAC，12 帧 / 0.4 秒，音视频时长一致。虚拟机为 ARM Windows 的 x64 仿真环境，DirectML 不可用时回退 CPU；无法替代实体显卡验证。
- 未替换原始模型；未覆盖原工作空间源码和照片。已保留上传的原始声音。

## 后续范围
