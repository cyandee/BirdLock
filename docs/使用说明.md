# BirdLock 鸟眼锁定 使用说明

BirdLock 把飞鸟连拍照片自动对齐到鸟眼，生成“鸟头不动、翅膀在扇”的连拍视频。识别、对齐、渲染和导出全部在你的 Mac 上本地完成，不联网、不上传照片。

---

## 一、准备

**系统要求**
- macOS 14 或更高版本，Apple 芯片（M 系列）或 Intel 处理器的 Mac 都可以运行；Apple 芯片速度明显更快。
- 「AI 光流补帧」需要 macOS 15.4 或更高版本。

**支持的照片**
- JPG、HEIF / HEIC、PNG、TIFF。暂不支持直接读取 RAW（如索尼 ARW），请先导出为 JPG 或 HEIF。
- 最好是同一组连拍：同一机身连续拍摄、构图大致相同。软件会读取拍摄时间（精确到亚秒），自动排序并识别连拍速度。

**安装**
1. 解压下载的压缩包，把「BirdLock.app」拖到「应用程序」文件夹。
2. 第一次打开时，系统可能提示“无法验证开发者”（本软件暂未做 Apple 公证）：先点「完成」，再打开「系统设置 → 隐私与安全性」，在下方找到 BirdLock，点「仍要打开」。以后就可以正常打开了。
3. 第一次打开会显示用户协议，阅读后点「同意并继续」。

## 二、五步快速上手

1. **导入**：把连拍照片所在的文件夹拖进窗口（也可以点左上角「导入」，或把文件夹拖到程序坞的 BirdLock 图标上）。
2. **等待分析**：软件依次进行「识别鸟 → 定位鸟头/鸟眼 → 亚像素配准 → 计算轨迹」，几十张照片通常十几秒。同一组照片第二次打开会直接读取缓存，几乎不用等。
3. **选构图**：在右侧「构图」页点一个构图风格，比如「前方留白」或「鸟眼居中」，然后按空格预览。
4. **选比例和画质**：在「输出」页选择画面比例（如 9:16 竖屏、16:9 横屏）、分辨率和播放速度。
5. **导出**：点右下角「导出…」（或按 ⌘E），选择保存位置。

## 三、界面一览

| 区域 | 内容 |
|---|---|
| 顶部工具栏 | 导入；连拍组切换（一个文件夹里有多组连拍时出现）；「成片预览 / 原图+识别」视图切换；导出 |
| 中间预览区 | 「成片预览」显示裁切、对齐后的成片效果；「原图+识别」显示原图和识别结果，可以在这里调整取景、修正鸟眼 |
| 播放控制栏 | 上一帧 / 播放 / 下一帧、循环、音乐预览开关、当前帧号和文件名、成片时长，以及「起点 / 终点 / 排除」 |
| 时间轴 | 「画面」轨道：彩色状态条（绿 = 识别到鸟眼，橙 = 鸟头推算，紫 = 手动修正，红 = 未识别或模糊，灰 = 已排除），下方是鸟眼位置、鸟头大小、清晰度曲线；点击或拖动可以跳转。「音乐」轨道：背景音乐的波形 |
| 右侧设置栏 | 「构图」「画面」「输出」三页设置，底部是成片规格和导出按钮 |

## 四、构图（「构图」页）

### 构图风格
一键套用常用组合：鸟眼居中、前方留白、头部特写、全身舒展、电影跟随、自然远近。套用后仍可继续微调下面的各项。

### 锁定
- **锁定点**：「鸟眼」（被遮挡时自动改用鸟头推算）或「鸟头中心」。
- **跟随方式**：最左边是「硬锁定」，鸟眼钉死在画面一点；往右拉，镜头像摄像机一样柔和跟随，鸟在画面里轻微浮动，更有现场感。

### 画面位置
拖动小方框里的圆点，设置鸟眼在成片中的位置。勾选「飞行方向自动留白」后，鸟朝左飞时会自动左右镜像，保证鸟的前方有空间。也可以在「原图+识别」里直接拖动取景框（见第五节）。

### 取景
- **取景范围**：成片短边等于鸟头长度的多少倍。数值越小鸟越大，越大画面越宽。可以拖滑块、点 −/+，或直接输入数值（2–300）。
- **用满原图**：把取景放到原图能容纳的最大范围。到达上限时会提示“已到原图大小上限”。
- **大小**：「锁定鸟的大小」让鸟在画面里大小不变；「固定取景」让鸟随远近自然变大变小。
- **大小平滑**：数值越大，鸟的大小变化越平缓。

### 画面边缘（鸟飞到原图边缘时）
- **平移取景，用满原图（推荐）**：取景框在原图内平移，尽量多用原图像素。鸟会暂时离开锁定点，但不会贴到成片边缘。
  - **鸟眼离画面边缘至少**：平移后鸟眼与成片边缘的最小距离。
  - **为此最多放大**：鸟太靠近原图边缘时，允许稍微放大来保持上面的距离；设为「不放大」则只平移。
- **放大避免越界**：始终保持鸟眼锁定，画面不够时放大。
- **模糊延展填充 / 黑边**：保持取景大小，超出原图的部分用模糊画面或黑色填充。

### 旋转
「不旋转」「锁定头部角度」「柔和校正倾斜」，以及角度微调。

## 五、在原图上调整取景和修正鸟眼（「原图+识别」视图）

切换到「原图+识别」（⌘T）后可以看到：
- **绿色框**：被跟踪的鸟；黄色虚线框是画面里的其他鸟。
- **白色虚线框**：这一帧的成片取景范围，框外变暗。
- **圆圈**：鸟眼位置。青色 = 识别到的鸟眼，橙色 = 鸟眼被遮挡、根据鸟头推算的位置，紫色 = 手动修正。
- 红点是识别到的鸟头关键点，方块是鸟头中心，细线是最近 20 帧鸟眼的轨迹。

### 直接拖动取景框
- 在虚线框内拖动：移动取景（鸟在成片里的位置随之改变）。
- 拖动四个角的白色小方块：放大或缩小取景范围。
- 这两项都是整组照片一起生效。

### 修正鸟眼
鸟眼被翅膀或树枝挡住时，软件会根据鸟头其他部位推算鸟眼位置，个别帧可能不准。修正方法：
1. 在成片预览里，推算帧的右上角会显示橙色「鸟头推算」和「修正」按钮，点「修正」；或者在「画面」页点「逐帧检查」；也可以按 E。
2. 软件会切换到原图、放大并跟随鸟头，同时打开修正工具。
3. 在鸟眼的准确位置点一下（按住可以拖动微调）。也可以不开工具，直接拖动圆圈。
4. 用工具栏的 ‹ › 按钮（或 [ ] 键）跳到上一个 / 下一个推算帧，逐帧检查。

修正后，这一帧作为强约束，前后帧会自动重新计算。点「撤销本帧修正」可以撤销，「画面」页的「清除全部修正」可以全部清除。完全没识别到鸟的帧，也可以用同样的方法手动标出鸟眼，标记后这一帧就能用进成片。

**放大查看**：工具栏可以选「全图 / 2× / 4× / 8×」（Z 键切换，触控板可双指缩放）。放大后画面跟随鸟头，并自动换成原图的清晰像素。

### 选择目标鸟
画面里有多只鸟、跟错了鸟时，点「选择目标鸟」，再点要跟踪的那只，软件会重新识别。

## 六、画面与选帧（「画面」页）

- **去闪烁**：统一相邻帧的曝光和白平衡，消除连拍中的亮度跳动；可调强度和平滑窗口。
- **曝光**：整体提亮或压暗。
- **跳过模糊帧**：按鸟头区域的清晰度自动跳过失焦、拖影的帧，可调判定标准。
- **跳过未识别到鸟的帧**。
- **排除单帧**：在播放控制栏点「排除」（X 键），时间轴上会变灰；「全部恢复」可以撤销。
- **起点 / 终点**：只导出中间一段。
- **识别与修正**：显示识别统计、推算帧数量；「重新识别」会保留你的手动修正。

## 七、输出（「输出」页）

| 设置 | 说明 |
|---|---|
| 画面比例 | 9:16、3:4、4:5、1:1、5:4、4:3、3:2、16:9、1.85:1、2:1、2.39:1、21:9，或自定义 |
| 分辨率 | 短边 720–4320 像素。下方会提示原图像素是否够用；放大超过 1 倍时画面会略软 |
| 帧率 | 24–120 fps |
| 速度 | 0.1×–2×。下方会显示“成片每秒展示多少张连拍” |
| 补帧 | 重复帧（清晰）、帧混合（顺滑）、AI 光流补帧（最顺滑，导出较慢，需要 macOS 15.4+） |
| 顺序与重复 | 正放、倒放、往返；重复次数；淡入淡出 |
| 编码 | H.264（兼容性最好）、HEVC（体积小）、ProRes 422 HQ / 4444（适合后期剪辑）；质量：标准 / 高 / 极高 |

### 对焦框
模仿索尼相机的鸟眼对焦显示，在成片里标出焦点位置，让观众始终看到焦点在哪里：
- 打开「在成片里显示对焦点」。
- 样式：方框（索尼鸟眼对焦）或四角框（追踪框）；颜色：绿 / 白 / 橙；可调大小和线宽。
- 「鸟眼被遮挡时框住鸟头」：鸟眼被挡住的帧改为框住整个鸟头，和相机的显示逻辑一致。
- 对焦框是根据识别结果画的示意标记，不代表拍摄时相机的实际对焦点。

### 背景音乐
1. 点「选择音乐…」，或把音频文件（MP3、M4A、WAV、AIFF 等）拖到时间轴的「音乐」轨道。
2. 「音乐」轨道显示整首歌的波形，蓝色高亮区域就是视频里会用到的那一段，**左右拖动高亮区域**选择片段（点击波形其他位置可以直接跳过去）。
3. 可调音量、淡入、淡出；音乐比视频短时可以循环。
4. 按空格预览时会同步播放音乐，控制栏的喇叭按钮可以静音预览。
5. 只有导出「视频」时会合成音乐（AAC 256 kbps）。请确认你有权使用所选音乐。

### 图片水印
1. 点「导入 PNG…」选择你的签名或 Logo（建议用透明背景的 PNG）。
2. 在「成片预览」里**直接拖动水印**调整位置，拖动右下角的圆点调整大小；也可以用九宫格按钮快速放到角落或居中。
3. 可调大小和不透明度，「导出时添加」开关可以随时关闭。
4. 水印会加到视频、GIF 和图片序列里。

### 文字水印
显示拍摄参数（机身、镜头、快门、光圈、ISO，可逐帧显示）和自定义文字，选择四个角之一，可调字号。

## 八、导出

点「导出…」（⌘E），选择类型：
- **视频**：MP4（H.264 / HEVC）或 MOV（ProRes），包含背景音乐。
- **对齐后的图片序列**：每张原图输出一张对齐裁切后的 JPEG。
- **GIF 动图**：最长边 720 像素，方便快速分享。

建议勾选「使用原图全分辨率渲染」（默认开启），画质最好。导出完成后可以点「在访达中显示」或「打开」。

## 十、常见问题

**跟错了鸟？** 切到「原图+识别」，点「选择目标鸟」，再点正确的那只。

**鸟眼位置不准、画面跳动？** 先看时间轴上的橙色帧（鸟头推算），用「逐帧检查」修正；也可以把「跟随方式」往右拉一点，或打开「跳过模糊帧」。

**鸟总是贴着画面边缘、被切掉？** 把「画面边缘」设为「平移取景，用满原图」，并适当调大「鸟眼离画面边缘至少」。

**取景已经拉到最大还是不够宽？** 点「用满原图」。如果提示已到原图大小上限，说明取景已经用到整张原图了。也可以换成更接近原图比例的画面比例（比如横拍的照片选 3:2 或 16:9）。

**画面发软？** 输出页如果提示“原图像素不足”，可以降低分辨率，或把取景放宽一些。

**占用了很多磁盘空间？** 缩略图和分析结果缓存在 `~/Library/Caches/BirdLock`，可以随时删除，下次打开同一组照片时会重新分析。

**会改动我的原始照片吗？** 不会。软件只读取原图，所有结果都另外保存。

**打开时提示“已损坏，无法打开”？** 这是 macOS 对未公证软件的拦截，并不是文件真的损坏。打开「终端」，运行下面这行命令后再打开即可：
`xattr -dr com.apple.quarantine /Applications/BirdLock.app`

**在哪里看用户协议和开源许可？** 菜单栏「BirdLock → 用户协议」和「BirdLock → 许可与第三方组件」。本软件以 AGPL-3.0 开源，源代码随安装包提供。
