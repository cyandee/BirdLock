# BirdLock 1.10.0 更新说明

Mac 与 Windows 统一为 1.10.0。已安装1.5.0或更新版本，可在软件内检查更新；关闭自动检查时请手动检查。

## 整组固定鸟眼

在「构图 → 鸟眼选择」点选要跟随的眼睛，可先查看末尾，再从任意清晰照片应用到当前连续组。固定模式保持同一眼标签，减少置信度变化造成的换眼；短暂遮挡显示推算，长时间缺少可靠观测时提示未跟踪。保留已有手动修正，支持恢复自动、撤销选择和工程保存。

## 自定义目标跟踪

新增「自定义目标」：拖出稳定区域，再在框内点击锁定点，从参考帧向前、向后跟踪本组。失锁处可补选参考关键帧；框和锁定点分别记录，沿用构图、预览、导出与工程流程。不新增模型权重。初版优先位置锁定，完全转身、长期遮挡、小目标或快速变形可能需要人工修正。

## Windows 飞机机头显卡后端

机头由固定 CPU 改为遵循设备设置，优先使用现有 DirectML，并提供 CPU 回退；保留原模型和四方向检查。按首轮实际节点分配更新设备状态，日志增加加载时间、推理时间和回退记录，便于 RTX 3080 等设备复测。实际速度取决于素材、算子和驱动，本次未完成 RTX 3080 实机测试，不承诺与鸟类模型同速。

操作与边界见《自定义目标与固定选眼》。请保留原片和工程；Mac 仍未做 Apple 公证，视频等既有实验限制继续适用。

## 从较早版本升级

1.6至1.9加入的视频导入、原声与增稳、383份镜头配置、工程保存与缓存管理继续保留，详见[此前累计说明](https://github.com/cyandee/BirdLock/blob/main/docs/更新说明-1.9.0.md)。更新前请保存工程并保留原素材。
