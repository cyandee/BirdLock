## 识别模型

**YOLO11m 鸟类检测模型**

- 来源：Ultralytics（https://github.com/ultralytics/ultralytics）
- 许可：AGPL-3.0
- 训练数据：COCO 数据集（标注采用 CC BY 4.0）

**eye-pose-v0 鸟头 / 鸟眼关键点模型**

- 来源：https://huggingface.co/synthet/eye-pose-v0
- 基于 Ultralytics YOLO11n-pose（AGPL-3.0）微调
- 训练数据：CUB-200-2011（Caltech-UCSD Birds），图片来自 Flickr，通常仅供非商业研究使用

## 飞机试验模式

使用IDEA-Research Grounding DINO tiny及ONNX Community量化转换（Apache-2.0），固定版本和SHA256见随包aircraft/manifest.json。飞机机身使用原COCO检测器，不加载鸟姿态模型；机头定位由独立部位网络与图像跟踪完成，真实连拍精度仍需要继续测试。aircraft/Licenses保留模型许可、ONNX Runtime MIT及官方完整第三方声明，来源见同目录README。

## 陀螺仪读取组件

BirdLockTelemetry 使用 [telemetry-parser](https://github.com/AdrianEddy/telemetry-parser) 的固定提交 `19bc11f8c13eaa07ec1988bf0a55884f3fcc0f96`，依上游 MIT OR Apache-2.0 许可使用。该辅助进程的 BirdLock 代码遵循项目的 AGPL-3.0 许可。此组件独立随包分发，不要求用户安装 Gyroflow；未链接 Gyroflow GUI 或防抖核心。

组件目录内 `Licenses/` 随附解析库完整 MIT/Apache 文本、Cargo 依赖名称/版本/来源/许可证及各依赖的声明、Rust 运行库版权声明。采用 Windows GNU 构建时另含 MinGW runtime 声明及 GCC Runtime Library Exception。Mac 的位置是 `Contents/Resources/Telemetry/Licenses/`，Windows 为 `_internal/telemetry/Licenses/`。`manifest.json` 固定解析库提交与组件校验值；`Licenses/checksums.json` 校验随包许可文本。源码与构建方式见 `tools/telemetry/` 和 `scripts/build_telemetry_helper.py`。
