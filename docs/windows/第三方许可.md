## 识别模型



**YOLO11m 鸟类检测模型**

- 来源：Ultralytics（https://github.com/ultralytics/ultralytics）
- 许可：AGPL-3.0
- 训练数据：COCO 数据集（标注采用 CC BY 4.0）

**eye-pose-v0 鸟头 / 鸟眼关键点模型**

- 来源：https://huggingface.co/synthet/eye-pose-v0
- 基于 Ultralytics YOLO11n-pose（AGPL-3.0）微调
- 训练数据：CUB-200-2011（Caltech-UCSD Birds），图片来自 Flickr，通常仅供非商业研究使用

## 飞机试验模式



使用IDEA-Research Grounding DINO tiny及ONNX Community量化转换（Apache-2.0），固定版本和SHA256见随包aircraft/manifest.json。飞机机身使用原COCO检测器，不加载鸟姿态模型；机头定位由独立部位网络与图像跟踪完成，真实连拍精度仍需要继续测试。aircraft/Licenses保留模型许可、ONNX Runtime MIT及官方完整第三方声明，来源见同目录README。
