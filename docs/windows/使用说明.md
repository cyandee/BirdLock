# BirdLock 鸟眼锁定 使用说明（Windows 版）



适用于 **1.4.0 测试版**。[下载安装包](https://github.com/cyandee/BirdLock/releases/tag/v1.4.0-beta.1) · 更新于 2026-10-19。

这份说明按导入、调整、配音和导出的顺序写。第一次用，可以先照着「五步快速上手」做一段，其他设置用到时再看。照片识别和视频合成都在自己的电脑上完成，不上传照片。

---

## 一、准备



**系统要求**

- Windows 10 / 11（64 位）。
- 推荐有独立显卡（NVIDIA / AMD / Intel Arc，支持 DirectX 12），AI 识别和视频编码会用显卡加速；没有独显也能用，速度慢一些。
- 内存 8 GB 以上，处理 5000 万像素以上的照片建议 16 GB。

**支持的照片**

- JPG、HEIF / HEIC、PNG、TIFF。暂不支持直接读取 RAW（如索尼 ARW），请先导出为 JPG 或 HEIF。
- 最好是同一组连拍：同一机身连续拍摄、构图大致相同。软件会读取拍摄时间（精确到亚秒），自动排序并识别连拍速度。

**安装（绿色版，无需安装）**

1. 从 GitHub 下载 `BirdLock-版本号-Windows-x64.zip`，解压到任意文件夹（比如 `D:\Tools\BirdLock`，也可以放在 U 盘里）。
2. 双击文件夹里的 **BirdLock.exe** 运行。第一次运行如果出现“Windows 已保护你的电脑”：点「更多信息」→「仍要运行」（本软件暂未做数字签名）。
3. 第一次打开会显示用户协议，阅读后点「同意并继续」。
4. 设置和缓存优先保存在程序文件夹的`data`中；程序目录不可写时，回退到`%LOCALAPPDATA%/BirdLock`。自行添加音频仍需保留源文件。卸载前请保存需要的成片与编辑，按实际位置处理应用及数据。

下载页附有 `SHA256SUMS.txt`，可以用来核对压缩包是否完整。移动程序时请保留整个文件夹。

## 二、五步快速上手



1. **导入**：把连拍照片所在的文件夹拖进窗口（也可以点左上角「导入」，或把文件夹拖到 BirdLock.exe 的图标上）。
2. **等待分析**：软件依次进行「识别鸟 → 定位鸟头/鸟眼 → 亚像素配准 → 计算轨迹」，几十张照片通常十几秒到一分钟（取决于显卡）。同一组照片第二次打开会直接读取缓存，几乎不用等。
3. **选构图**：在右侧「构图」页点一个构图风格，比如「前方留白」或「鸟眼居中」，然后按空格预览。
4. **选比例和画质**：在「输出」页选择画面比例（如 9:16 竖屏、16:9 横屏）、分辨率和播放速度。
5. **导出**：点右下角「导出…」（或按 Ctrl+E），选择保存位置。

## 三、界面一览



| 区域 | 内容 |
|---|---|
| 顶部工具栏 | 导入；连拍组切换（一个文件夹里有多组连拍时出现）；「成片预览 / 原图+识别」视图切换；导出 |
| 中间预览区 | 「成片预览」显示裁切、对齐后的成片效果；「原图+识别」显示原图和识别结果，可以在这里调整取景、修正鸟眼 |
| 播放控制栏 | 上一帧 / 播放 / 下一帧、循环、音乐预览开关、当前帧号和文件名、成片时长，以及「起点 / 终点 / 排除」 |
| 时间轴 | 「画面」轨道：彩色状态条（绿 = 识别到鸟眼，橙 = 鸟头推算，紫 = 手动修正，红 = 未识别或模糊，灰 = 已排除），下方是鸟眼位置、鸟头大小、清晰度曲线；点击或拖动可以跳转。「音乐」轨道：背景音乐的波形 |
| 右侧设置栏 | 「构图」「画面」「输出」三页设置，底部是成片规格和导出按钮 |

## 四、构图（「构图」页）



### 构图风格


一键套用常用组合：鸟眼居中、前方留白、头部特写、全身舒展、电影跟随、自然远近。套用后仍可继续微调下面的各项。

### 锁定


- **锁定点**：「鸟眼」（被遮挡时自动改用鸟头推算）或「鸟头中心」。
- **跟随方式**：最左边是「硬锁定」，鸟眼钉死在画面一点；往右拉，镜头像摄像机一样柔和跟随，鸟在画面里轻微浮动，更有现场感。

### 画面位置


拖动小方框里的圆点，设置鸟眼在成片中的位置。勾选「飞行方向自动留白」后，鸟朝左飞时会自动左右镜像，保证鸟的前方有空间。也可以在「原图+识别」里直接拖动取景框（见第五节）。

### 取景


- **取景范围**：成片短边等于鸟头长度的多少倍。数值越小鸟越大，越大画面越宽。可以拖滑块、点 −/+，或直接输入数值（2–300）。
- **用满原图**：把取景放到原图能容纳的最大范围。到达上限时会提示“已到原图大小上限”。
- **大小**：「锁定鸟的大小」让鸟在画面里大小不变；「固定取景」让鸟随远近自然变大变小。
- **大小平滑**：数值越大，鸟的大小变化越平缓。

### 画面边缘（鸟飞到原图边缘时）


- **平移取景，用满原图（推荐）**：取景框在原图内平移，尽量多用原图像素。鸟会暂时离开锁定点，但不会贴到成片边缘。
  - **鸟眼离画面边缘至少**：平移后鸟眼与成片边缘的最小距离。
  - **为此最多放大**：鸟太靠近原图边缘时，允许稍微放大来保持上面的距离；设为「不放大」则只平移。
- **放大避免越界**：始终保持鸟眼锁定，画面不够时放大。
- **模糊延展填充 / 黑边**：保持取景大小，超出原图的部分用模糊画面或黑色填充。

### 旋转


「不旋转」「锁定头部角度」「柔和校正倾斜」，以及角度微调。

## 五、在原图上调整取景和修正鸟眼（「原图+识别」视图）



切换到「原图+识别」（Ctrl+T）后可以看到：

- **绿色框**：被跟踪的鸟；黄色虚线框是画面里的其他鸟。
- **白色虚线框**：这一帧的成片取景范围，框外变暗。
- **圆圈**：鸟眼位置。青色 = 识别到的鸟眼，橙色 = 鸟眼被遮挡、根据鸟头推算的位置，紫色 = 手动修正。
- 红点是识别到的鸟头关键点，方块是鸟头中心，细线是最近 20 帧鸟眼的轨迹。

### 直接拖动取景框


- 在虚线框内拖动：移动取景（鸟在成片里的位置随之改变）。
- 拖动四个角的白色小方块：放大或缩小取景范围。
- 这两项都是整组照片一起生效。

### 修正鸟眼


鸟眼被翅膀或树枝挡住时，软件会根据鸟头其他部位推算鸟眼位置，个别帧可能不准。修正方法：

1. 在成片预览里，推算帧的右上角会显示橙色「鸟头推算」和「修正」按钮，点「修正」；或者在「画面」页点「逐帧检查」；也可以按 E。
2. 软件会切换到原图、放大并跟随鸟头，同时打开修正工具。
3. 在鸟眼的准确位置点一下（按住可以拖动微调）。也可以不开工具，直接拖动圆圈。
4. 用工具栏的 ‹ › 按钮（或 [ ] 键）跳到上一个 / 下一个推算帧，逐帧检查。

修正后，这一帧作为强约束，前后帧会自动重新计算。点「撤销本帧修正」可以撤销，「画面」页的「清除全部修正」可以全部清除。完全没识别到鸟的帧，也可以用同样的方法手动标出鸟眼，标记后这一帧就能用进成片。

**放大查看**：工具栏可以选「全图 / 2× / 4× / 8×」（Z 键切换，也可以用鼠标滚轮缩放）。放大后画面跟随鸟头，并自动换成原图的清晰像素。

### 选择目标鸟


画面里有多只鸟、跟错了鸟时，点「选择目标鸟」，再点要跟踪的那只，软件会重新识别。

## 六、画面与选帧（「画面」页）



- **去闪烁**：统一相邻帧的曝光和白平衡，消除连拍中的亮度跳动；可调强度和平滑窗口。
- **曝光**：整体提亮或压暗。
- **跳过模糊帧**：按鸟头区域的清晰度自动跳过失焦、拖影的帧，可调判定标准。
- **跳过未识别到鸟的帧**。
- **排除单帧**：在播放控制栏点「排除」（X 键），时间轴上会变灰；「全部恢复」可以撤销。
- **起点 / 终点**：只导出中间一段。
- **识别与修正**：显示识别统计、推算帧数量；「重新识别」会保留你的手动修正。

## 七、多组连拍和播放顺序



导入时可以选择「归为一组」，或按拍摄间隔自动分成多组。直接拖入照片默认按间隔分组，之后也可以合并。

在顶部切换查看单组，选择「合并选中组 → 同一视频」并勾选需要的组，就能接成一个视频。在「连拍与特写」的片段播放顺序中，用上移、下移调整先后顺序。

每组内部仍按拍摄时间排列，保留各自估算的连拍速度。组与组之间直接切换，不做跨组光流或混合补帧。这里合并的是照片生成的片段，暂不支持外部视频。

修正、排除和特写会跟着原照片移动。若特写跨了两组，需要先把范围缩到同一组内。排序后，裁剪范围会恢复为全部，软件会提示；音轨仍按视频秒数定位，排好顺序后记得重新试听卡点。

构图和画面设置对合并后的视频整体生效。重新打开同一批照片，会保留选择的组顺序。

## 八、关键帧特写



想在某一张照片上停留久一点，可以把它设成特写：

1. 选中照片，在「输出 → 连拍与特写」创建特写。
2. 选择起始照片、替换结束照片，再设展示秒数。它会替换这段照片原本的时长。
3. 调节放大、横向与纵向构图，参数只影响这段特写。默认以主体头部为中心，取景会限制在照片内。
4. 需要的话打开动态四角框，选颜色，点「预览这张特写」。时间轴上的紫色横条是替换范围。
5. 新特写默认在开始时响一次单张快门，可以关闭或单独调音量；照片停得再久，也只响一次。

特写不能重叠，冲突时会提示。删除特写会恢复原照片，起始照片被排除或裁掉后，这段特写也不会加入成片。修改起点超过原终点时，终点会自动后移。

倒放或重复视频时，快门声会按实际特写开始的位置播放。旧版本保存的特写默认保持无声，需要的话手动打开。

## 九、输出（「输出」页）



| 设置 | 说明 |
|---|---|
| 画面比例 | 9:16、3:4、4:5、1:1、5:4、4:3、3:2、16:9、1.85:1、2:1、2.39:1、21:9，或自定义 |
| 分辨率 | 短边 720–4320 像素。下方会提示原图像素是否够用；放大超过 1 倍时画面会略软 |
| 帧率 | 24–120 fps |
| 速度 | 0.1×–2×。下方会显示“成片每秒展示多少张连拍” |
| 补帧 | 重复帧（清晰）、帧混合（顺滑）、光流补帧（最顺滑，导出较慢） |
| 顺序与重复 | 正放、倒放、往返；重复次数；淡入淡出 |
| 编码 | H.264（兼容性最好）、HEVC（体积小）、ProRes 422 HQ / 4444（适合后期剪辑）；质量：标准 / 高 / 极高 |

### 硬件加速（Windows 版）


- **AI 识别**：默认「自动（优先独立显卡）」，笔记本上会自动选独显而不是核显；也可以指定某块显卡，或只用 CPU。改了以后下次识别时生效。
- **图像缩放 / 变换用显卡（OpenCL）**：渲染和导出时用显卡做重采样，默认打开。
- **视频编码**：默认「自动」，有 NVIDIA 显卡时用 NVENC，AMD 用 AMF，Intel 用 Quick Sync，都没有时用 CPU 编码。导出完成后会显示用了哪个编码器。

### 对焦框


可以给成片加上类似相机取景器的对焦框：

- 打开「在成片里显示对焦点」。
- 样式：方框（索尼鸟眼对焦）或四角框（追踪框）；颜色：绿 / 白 / 橙 / 黑；眼、头、身体分别配色，身体大小独立调节。
- 「鸟眼被遮挡时框住鸟头」：鸟眼被挡住的帧改为框住整个鸟头。
- 鸟眼、鸟头、鸟身可以单独或组合显示，分别改颜色；鸟身框大小独立调节，覆盖检测到的展开翅膀。缩小框后可能包不住整个翅膀，原图外或已裁掉的部分也无法显示。
- 鸟身闪烁和画面内侧快门边框可以分别设置。快门边框大小、颜色可调，最高 120 次/秒；视频帧率较低时，高频可能看起来静止或变慢。
- 这些框是根据识别结果画出的效果，不代表拍摄时相机的实际对焦位置。

### 图片水印


1. 点「导入 PNG…」选择你的签名或 Logo（建议用透明背景的 PNG）。
2. 在「成片预览」里**直接拖动水印**调整位置，拖动右下角的圆点调整大小；也可以用九宫格按钮快速放到角落或居中。
3. 可调大小和不透明度，「导出时添加」开关可以随时关闭。
4. 水印会加到视频、GIF 和图片序列里。

### 文字水印


显示拍摄参数（机身、镜头、快门、光圈、ISO，可逐帧显示）和自定义文字，选择四个角之一，可调字号。

## 十、快门声、背景音乐和多轨



### 添加背景音乐



1. 点「选择音乐…」，或把音频文件拖到时间轴的「音乐」轨道。支持 MP3、M4A、WAV、AIFF 等。
2. 波形中的蓝色高亮区域是实际使用的片段，左右拖动它选择音乐起点，点击其他位置也能跳过去。
3. 调音量、淡入、淡出，音乐比视频短时可开启循环。
4. 按空格试听，喇叭按钮可以静音预览。

### 添加快门和其他声音



在「音效与多轨」里添加内置快门，也可以选自己的音频。先选相机，再选 fps 或录音：

| 相机 | 录音 |
|---|---|
| 索尼 A1 II（A1M2） | 5 / 10 / 15 / 20 / 30 fps |
| 索尼 A9 III（A93） | 60 / 120 fps |
| 索尼 A7 V（A7M5） | Hi+ 30 fps / Mid 15 fps |
| 索尼 A7R VI（A7R6） | 原录音，帧率暂未确认 |
| 尼康 Z8 | 20 fps |

各档使用对应完整录音，原速循环。旧 A1 II 的 10 fps 和旧菜单显示的 30 fps 会对应到新录音，其他失效声音会提示重新选择。

每条轨道都可以独立静音、调音量、视频起点、素材起点、长度、循环和淡入淡出，时间轴上的音频块可以拖动。长度为 0 表示用到成片结束；不循环的声音播放完后保持静音。

快门、背景音乐和其他声音可以同时使用。内置声音不用保留原始上传文件，自行添加的音频则要保留源文件。只有视频包含声音，GIF 和图片序列没有音轨。

### 音乐卡点



加入背景音乐后，可以查看音乐节拍、能量高潮和画面候选，选择一个音乐时刻与画面对齐。画面候选参考主体展开程度、清晰度和识别结果；分析针对主背景音乐，其他音轨手动调整。

这些位置只是参考，我建议对齐后完整听一遍。若音乐候选太早，无法通过移动素材起点对齐，可以换一张更早的画面。

连拍和单张快门的来源见[音效说明](../../SharedResources/Audio/README.md)。单拍使用 benjohansen 的 Canon Digital Rebel 录音，CC0 许可，与上表各型号的连拍声分开使用。公开作品前也请确认背景音乐的授权。

## 十一、飞机模式



导入前选择「飞机（试验）」，程序会检测机身并定位、跟踪机头。机头和包含机翼的机身框可以分别开关、配色、调大小，快门模拟照常使用。

鸟类与飞机分别保存构图、输出、对焦框设置和识别编辑，照片分组与音轨共用。切换期间取消，会恢复上一份分析。

这是试验功能，小目标、倒置、遮挡和复杂角度可能找错机头。请切到「原图+识别」逐帧看一下，用「修正机头」调整当前帧。暂时缺少足够的真实连拍测试，具体情况见[飞机识别](../飞机识别调研.md)。

飞机分析比鸟类慢，机头模型使用 CPU，取消时需要等当前一次推理结束。Mac 完整测试进程的内存峰值约 3.53 GB，内存较小的电脑可能会比较吃力。

## 十二、导出



点「导出…」（Ctrl+E），选择类型：

- **视频**：MP4（H.264 / HEVC）或 MOV（ProRes），包含背景音乐。
- **对齐后的图片序列**：每张原图输出一张对齐裁切后的 JPEG。
- **GIF 动图**：最长边 720 像素，方便快速分享。

建议勾选「使用原图全分辨率渲染」（默认开启），画质最好。导出完成后可以点「在文件夹中显示」或「打开」。

## 十三、快捷键



| 按键 | 功能 |
|---|---|

## 十四、常见问题



**跟错了鸟？** 切到「原图+识别」，点「选择目标鸟」，再点正确的那只。

**鸟眼位置不准、画面跳动？** 先看时间轴上的橙色帧（鸟头推算），用「逐帧检查」修正；也可以把「跟随方式」往右拉一点，或打开「跳过模糊帧」。

**鸟总是贴着画面边缘、被切掉？** 把「画面边缘」设为「平移取景，用满原图」，并适当调大「鸟眼离画面边缘至少」。

**取景已经拉到最大还是不够宽？** 点「用满原图」。如果提示已到原图大小上限，说明取景已经用到整张原图了。也可以换成更接近原图比例的画面比例（比如横拍的照片选 3:2 或 16:9）。

**画面发软？** 输出页如果提示“原图像素不足”，可以降低分辨率，或把取景放宽一些。

**占用了很多磁盘空间？** 缩略图和分析结果缓存在程序文件夹的 `data\\cache` 里（菜单「文件 → 清空缓存」），程序目录不可写时会放到 `%LOCALAPPDATA%/BirdLock`。清空后需要重新分析，也会失去手动修正、排除帧和特写设置，请先保存需要的成片。

**会改动我的原始照片吗？** 不会。软件只读取原图，所有结果都另外保存。

**杀毒软件报毒 / 被拦截？** Windows 包暂时没有数字签名。请先核对下载来源和校验值，保留拦截提示发给我，方便排查。

**显卡没有被用上？** 打开「输出 → 硬件加速」：「AI 识别」选你的独立显卡，「视频编码」选 NVIDIA NVENC / AMD AMF / Intel Quick Sync。卡片里会显示当前用的是哪块显卡。笔记本建议插上电源使用。

**导出报错或花屏？** 先把「视频编码」改成「软件编码（CPU）」试试；如果是显卡驱动的问题，可以关掉「图像缩放 / 变换用显卡」。

**在哪里看用户协议和开源许可？** 菜单「帮助 → 用户协议」和「帮助 → 许可与第三方组件」。本软件以 AGPL-3.0 开源，源代码在GitHub公开；分发安装包时应附对应提交源码与校验值。
