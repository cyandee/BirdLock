## 本批内容

- 鸟眼、鸟头、鸟身框独立选择和组合显示；鸟身框覆盖检测到的展开翅膀。
- 鸟身框闪烁与独立的画面内侧快门闪烁边框，可调每秒 1—15 次；新增效果默认关闭。
- 两端版本由 VERSION 统一；反馈入口改为邮箱 cyanodee@gmail.com，提示欢迎通过邮箱反馈问题与建议。
- 保留原有九文件 Windows 修复；新增关闭窗口时的队列与回调清理、最新修正保存。
- Mac 分发包检查执行文件、权限、双架构、模型与关键点描述、版本及随包说明。

## 请优先试用

1. 安装本批包，检查关于页版本 1.1.0 与帮助菜单邮箱复制入口。
2. 导入连拍，打开「输出 → 对焦框」；分别测试鸟眼、鸟头、鸟身及组合显示。
3. 比较鸟身框是否包含展开的翅膀；照片本身或取景裁切之外的部分无法恢复。
4. 测试鸟身框闪烁及独立快门闪烁边框，比较预览与导出；频率按成片时间计算。
5. Windows 来回切换设置页、缩放窗口、播放、修正后关闭再打开，并尝试竖屏 HEVC 导出。
6. 如有此前无法打开的 Mac，请从本批 DMG 安装复测，并保留错误提示与安装包校验信息。
