# BirdLock 1.9.0 更新说明

这次更新汇总了从 **1.5.0 到 1.9.0** 的变化，Mac 与 Windows 版本一致。除了照片连拍，现在也可以导入视频进行主体锁定和增稳；编辑可以保存为工程，下次接着调整。

## 支持导入视频

- 从「文件 → 导入视频（实验）…」选择视频，也可以直接拖入视频文件。
- 自行选择片段起点、时长和采样帧率，导入前可查看实际处理范围和帧数。
- 支持鸟眼、鸟头或飞机机头锁定，结合自动裁切，让主体保持在画面中的指定位置。
- 视频原声会自动导入，不必再单独添加音频。

## 更强的画面防抖，减少主体大小跳动

- 「画面」页新增图像防抖、陀螺仪防抖和自动融合，可按素材选择；也可选择锁定主体或保留较平滑的相机运动。
- 增加自动裁切、固定裁切与强力防抖预设，最大附加裁切可设至 **8×**，允许牺牲更多视野换取更强的稳定效果。
- 优化「锁定主体大小」，减少识别波动和防抖缩放造成的大小忽大忽小；修正达到裁切上限时的锁定点偏移。
- 防抖方法旁增加悬浮说明，帮助了解不同方式的适用条件与取舍。

## 陀螺仪同步与镜头配置

- 支持读取兼容视频中内嵌的陀螺仪数据，也可以导入 GCSV，以及包含运动采样或引用可用本地运动记录的 Gyroflow 工程。
- 提供陀螺仪与视频画面的自动同步，以及手动毫秒偏移调整；数据不足或同步不可靠时会提示。
- 内置 **383 份 Gyroflow 镜头配置**。搜索与选择合并在同一个框中，可按品牌、机身、镜头、焦距或拍摄模式查找。
- 支持导入 Gyroflow 静态镜头 JSON，以及读取索尼 XML 中的机身、镜头等信息来辅助匹配。
- 经核对且唯一匹配的组合可自动选择；其他配置需要确认拍摄模式。没有对应组合时，可从「查找配置」进入镜头库或查看标定方法。

## 原声与特写衔接更自然

- 视频原声随裁剪、排除帧、变速、倒放、往返和重复播放排列，可独立调节音量与淡入淡出。
- 特写期间自动暂停内置的相机连拍快门声，结束后恢复；特写单张快门声和背景音乐仍按设置播放。
- 视频原声在特写定格期间静音，结束后继续，避免定格画面仍播放原视频的声音。

## 保存工程，下次接着编辑

- 新增「保存工程」「工程另存为」「打开工程」和「关闭工程」，使用 **`.birdlock`** 工程文件。
- 保存识别结果、手动修正、排除帧、特写、分组顺序、裁剪、构图、防抖、输出设置、音轨和水印，重新打开后可继续调整，无需重新识别主体。
- 更换素材、关闭或退出时，未保存的编辑会询问是否保存；取消保存会保留当前工作。
- 支持按相对路径查找素材，找不到原片时可以重新定位素材文件夹。

**工程引用原片，不复制素材。请同时保留视频、照片、自行添加的音乐和水印文件。**

## 导出后清理过程文件，控制缓存占用

- 视频成功导出后，可选择保留过程文件，或「保存工程并清理」。只有工程保存成功，才会清理本次过程文件并关闭当前工作。
- 清理后保留原片、导出成品、工程与编辑记录；下次打开工程时按需重建过程文件，沿用已保存的识别结果与编辑。
- 新增「文件 → 缓存管理」，默认缓存上限 **20GB**，可自行调整，设为 **0** 表示不限制；也可关闭导出后的清理询问。
- 优先清理较久未使用且可重建的内容，当前工程和进行中的任务受保护；受保护内容超过上限时会保留并提示。

## 其他体验与性能改进

- 视频导出默认采用原视频名称和所在目录；飞机模式使用「机头锁定」文件名后缀。
- 导入参数错误、镜头搜索尚未确认、没有可导出画面等情况会提前提示，减少无效操作。
- 锁定主体大小时，固定裁切开关显示实际状态；没有可用陀螺仪数据时，禁用无效同步操作。
- 根据 CPU、内存和图像尺寸调整识别与渲染并行度，改善高配电脑的资源利用，同时为低内存和低电量设备保留处理余量。实际速度取决于素材与硬件。

## 使用前看一下

- 视频导入仍为实验功能，目前按 **SDR、每次最多120秒或3600帧** 处理，不保留 HDR；暂不支持滚动快门逐行校正和动态镜头补偿。
- 陀螺仪数据取决于相机型号与拍摄设置，并非所有视频都包含。没有可用数据时可以使用图像防抖；索尼 XML 也不一定包含陀螺仪或镜头标定数据。
- 大幅裁切会损失视野和细节，防抖不能消除已经拍出的运动模糊。建议先选短片段，对比不同设置。
- 原声变速会同时改变音高，目前没有保调变速。
- 1.9 之前导入的视频，如保存工程时提示缺少重建信息，重新导入一次即可。
- 「打开工程」使用 **⌘O / Ctrl+O**；「保存工程」使用 **⌘S / Ctrl+S**。照片文件夹导入改为 **⌥⌘O / Ctrl+Alt+O**。

## 从 1.5.0 更新

请先完成当前工作再安装更新。Mac 在「BirdLock → 检查更新」，Windows 在「帮助 → 检查更新」中按提示操作；开启自动检查的用户也可以等待更新提示。更新不会替你开启此前关闭的自动检查设置。

如果无法联网或更新未完成，可以使用同一版本的完整安装包。Windows 手动安装时请保留原有 `data` 数据目录。Mac 仍未做 Apple 公证，首次安装的系统确认要求不变。
