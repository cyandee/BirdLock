# BirdLock 1.4 功能验收清单

本清单记录已完成的本地开发/自动回归与仍需真实素材/设备验证的范围，不代表真实素材精度或所有设备均已验收。当前版本为1.4.0，以v1.4.0-beta.1发布双平台测试包及公开源码，旧交付包不变；飞机试验模式已接入，真实连拍精度尚未验收，正式下载入口和Apple分发继续暂缓。

## 已明确的功能范围

- 照片导入与软件内照片片段成片，不添加外部视频片段。
- 鸟眼、鸟头、包含展开翅膀的鸟身框可分别选择、配色，鸟身可调整大小；快门模拟保留独立颜色、大小和1—120次/秒。
- 选中多组连拍照片接入同一视频，允许切换单组；不同组保留自己的连拍速度和目标，不跨切换处补帧。
- 特写替换照片原时段，独立时长、缩放、构图和动态框。
- 快门声与背景音乐等多轨共存；音乐候选辅助卡点，维护者试听决定。
- 飞机最终要求机头与机身识别、框选及快门模拟。采用自动部位网络与图像跟踪，手动标记用于纠错；按维护者确认，未降级为纯手动路线。

## 试用材料与记录

至少准备两组同一只鸟但拍摄中断的连拍，以及两组不同鸟或不同拍摄速度的照片；另外准备遮挡、无主体、横竖照片和一次性测试副本。音乐用可合法使用的节奏明显音频及静音片段。飞机需要正面、侧面、斜视、小目标和遮挡的真实连拍，不能用单张重复生成的片段代替真实跟踪验收。

记录系统版本、应用版本、处理照片数量、出现问题的操作及预览/导出差异。避免在截图和日志中分享私人目录或无关账号信息。重要照片保留原件，缓存清除测试仅用一次性副本。

| Mac启动与导出 | 通用包在Apple芯片与Intel支持系统启动，测试中文文件名路径；受影响设备复测原UTF-8报错。高分辨率、大倍率鸟身框导出无画外位图暴涨，不在画面边缘画假框 | 结构/资源/临时签名与大框导出通过；原报错未复现，实体Intel与受影响设备待测 |
| Windows稳定性 | 重复导入、切页、缩放窗口、播放、导出、关闭；中途取消和失败后能恢复，字体/高DPI不遮挡。实体x64显卡补测，不能以ARM虚拟机替代 | VM成品80次布局与两编码导出通过；实体显卡待测 |
