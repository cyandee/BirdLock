# 固定选眼、自定义目标与飞机加速

适用于 Mac / Windows **1.10.0**。[安装包与更新文件](https://github.com/cyandee/BirdLock/releases/tag/v1.10.0)使用相同版本，旧版与回滚材料保留。

## 整组固定同一只鸟眼

在「构图 → 鸟眼选择」点击「在原图点选要固定的眼睛」，浏览到清晰照片，点击要跟随的眼睛。可以先看完末尾，从最后一张开始选择，不要求选第一张。可靠眼部候选会用圆圈和数字标出；直接点选图上的眼睛，避免鸟自身左右与屏幕左右的歧义，候选不可靠时换一张照片。

选择应用到当前连续组，合并组分别保存。「恢复自动」恢复原方式，「撤销选眼」撤销上次选择。固定模式保持选中的眼睛标签，不因另一只眼置信度变高而换眼。短暂遮挡可根据头部和邻近观测推算；离可靠眼部观测或手动修正过远时标为未跟踪，默认跳过。模型仍可能误标左右眼，转头后请检查。

已有手动修正优先保留。如果某帧曾手动标在另一只眼，应撤销那一帧修正后检查或重新校正。选眼不改变拍摄时的真实对焦，也不能恢复原片已经丢失的清晰度。

## 自定义动物、昆虫和局部位置

1. 顶部选择「自定义目标」，导入同一段连续照片。软件准备预览，不调用鸟类或飞机模型。
2. 在任意一张清晰照片上拖出稳定、有纹理的区域，优先选头部、胸部或躯干局部，避开大面积背景、透明区域和持续变形的翅膀。
3. 在框内点击需要固定的位置，例如眼睛；想按区域中心跟随时点击中心即可。
4. 程序从参考帧向前、向后跟踪本组。跟踪框描述外观，锁定点描述成片对齐位置，它不必位于框中心。
5. 失锁处在清晰照片重新框选、点击，加入参考关键帧。当前组重算，其他组保留；可移除当前参考关键帧。

可靠跟踪、短距推算、失锁分别显示。只对两侧有可靠观测的短缺口推算；长缺口、出画再入画、完全转身、极小目标或相似个体交叉可能需要人工确认。一次框选不保证完成所有素材。

不新增模型权重。Mac 使用系统 Vision 和局部相位配准；Windows 使用现有 OpenCV 的局部特征、前后向检查、鲁棒变换和有限范围模板搜索。初版优先位置锁定，默认固定取景，不提供自定义目标自动旋转估计。两端后端不同，实际效果需用自己的素材检查。

构图、预览、导出、音乐和水印沿用现有流程，默认导出后缀为「目标锁定」。对焦框中的锁定点和区域框表示用户选择，不代表识别出了动物身体部位。

## 保存与恢复

`.birdlock` 工程保存选眼、参考框、局部锁定点和逐帧结果。重开不重新调用神经网络，预览缓存按需重建，仍需保留原照片。1.10 两端可以共享这些记录；旧版不支持自定义主体，请用新版本打开新工程。

## Windows 飞机识别与 RTX 3080 复测

此前机身检测可以使用显卡，但机头固定为 CPU。1.10 机头推理遵循硬件设置：自动或选定显卡优先使用现有 DirectML，选择 CPU 时仍用 CPU；不另装 CUDA 运行库或新增权重。

DirectML 使用串行推理、关闭不兼容的内存模式，并固定已知文本输入维度。初始化或推理失败时记录原因并回退 CPU。机头仍用原模型和四方向一致性检查，不以减少检查方向冒充加速。

设备状态先显示后端待验证，再按首轮实际节点分配区分 GPU、GPU/CPU 混合或 CPU。诊断日志记录加载时间、推理调用次数/时间、节点分配和回退原因。节点个数不等于 GPU 占用率，也不是纯 GPU 内核耗时；解码和部分算法仍使用 CPU。

在 RTX 3080 上用同一批照片、同一设置，分别选择 CPU 和自动/RTX 3080，再点「重新识别」，避免只读旧缓存。比较完整分析时间并检查日志；异常时用「帮助 → 导出诊断日志」。本机没有该显卡，本地模拟后端或 Mac 上 Qt 测试不等于 RTX 3080 实测提速。

Windows 实体设备验收继续由用户完成，本轮未启动虚拟机；Mac 仍未做 Apple 公证，既有视频实验边界保留。
