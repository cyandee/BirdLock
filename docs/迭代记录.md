# 更新记录

## 1.10.0 · 固定选眼与通用跟踪（2026-11-04）

- 任意清晰参考帧固定同一只鸟眼，当前连续组内保持选择，支持恢复自动、撤销与工程保存。
- 自定义目标先框选稳定区域、再点选锁定点，双向跟踪并可补充关键帧，无新增模型权重。
- Windows飞机机头由固定CPU改为优先DirectML，失败回退CPU，记录实际节点分配与耗时；RTX3080实际提速待实机复测。

[下载1.10.0](https://github.com/cyandee/BirdLock/releases/tag/v1.10.0)，[操作与限制](自定义目标与固定选眼.md)。旧版和回滚材料保留。

## 1.9.0 · 工程与缓存（2026-11-01）

- 保存、打开及另存为 `.birdlock` 工程，下次沿用识别结果、手动修正、特写、分组顺序、音轨、裁剪和防抖等设置继续编辑。更换素材和关闭时询问保存，取消保存保留当前工作。
- 视频成功导出后可选择保留过程文件，或先保存工程再关闭并清理JPEG/PCM与缩略图；下次从原片恢复缓存，使用已有识别结果。
- 新增缓存管理，默认20GB上限、0不限制，优先清理较久未用且可重建的文件，当前任务与编辑记录受保护；支持关闭导出后询问。
- 两端使用同一工程格式；工程引用原片及外部音乐/水印，不复制素材。移动后可按相对目录查找或重新定位。

[1.9.0正式版已发布](https://github.com/cyandee/BirdLock/releases/tag/v1.9.0)，两端版本一致，1.5可从软件内直接更新。升级后首次启动显示累计说明，并可在帮助菜单再次查看。Windows实体电脑运行仍由用户复测；云端检查与物理设备验收有区别。操作见[工程与缓存管理](工程与缓存管理.md)，完整变化见[累计更新说明](更新说明-1.9.0.md)。

- 空白页同时提示照片和视频入口；完成导入、构图/画面/输出、原声与导出的界面审查和两种窗口宽度检查。范围及证据见[体验审查](界面与体验审查.md)。

## 1.8.0 · 本地强力防抖候选（2026-11-01，尚未发布）

- 最大附加裁切提高至 8×，平滑时间提高至 10 秒，加入 6× 强力防抖预设和固定裁切，适合愿意牺牲视野换取稳定的片段。
- 图像、陀螺仪、自动融合方法旁增加悬浮说明，解释使用条件和利弊。
- 主体大小锁定加入相机尺度补偿、稳健尺寸曲线与固定附加裁切，减少检测噪声和防抖缩放造成的大小跳动；修正受限裁切时的锁定点偏移。
- 从固定 Gyroflow 数据库新增 375 份真实静态配置，共 383 份，支持品牌中文名、型号、镜头和模式搜索。新增条目需手动核对模式，原有精确匹配保留。
- 按 CPU、内存和图像尺寸限制并行工作与预取；高配 Mac 使用独立预测实例并行推理，常规导出有序并行渲染，低配与低电量设备保留保守预算及回退。

两端版本统一为 1.8.0；Mac 本地验证，Windows 由用户实机测试。仅本地交付，未推送、未发布；公开安装包和更新源仍为 1.5.0。测量与适用边界见[视频指南](视频导入与镜头配置.md)。

## 1.7.0 · 本地增稳候选（2026-11-01，尚未发布）

- 在「画面」加入独立视频防抖：图像运动估计、陀螺仪姿态平滑、自动融合和自适应裁切；可选择主体锁定或平滑相机运动。
- 原片陀螺仪读取、运动相关自动同步及手动毫秒微调；可导入 GCSV、含运动数据的 Gyroflow 工程或相机原片。周期歧义、数据断档和同步可信度不足不会标为成功。
- 视频原声自动导入为独立音轨，随剪辑、变速、倒放和重复排列；特写定格期间静音，结束后继续。音量、淡入淡出和移除均可单独调节。
- 自动读取机身/镜头与 Sony XML 身份，内置 8 组真实 Gyroflow 镜头配置，精确唯一匹配时自动选择；未匹配时提供查找和标定入口。XML 中没有的畸变或陀螺仪不会凭空补全。
- 导入面板删除原先介绍缓存及实现限制的解释段落。修正实际 Sony 高帧率原片的片尾采样边界，保留最后有效画面。

两端源码与本地候选版本统一为 1.7.0；公开安装包、标签和在线更新源仍为 1.5.0。Windows 候选复用已核验的 1.6.0 运行库，重新编入当前程序与资源并做静态核验；用户已明确决定本次不做 Windows 运行验证，后续在实体电脑自行测试。操作和实测范围见[视频、原声与增稳指南](视频导入与镜头配置.md)。

## 1.6.0 · 本地实验候选（2026-10-31，尚未发布）

- 特写期间自动暂停内置相机连拍声，结束后按原时间轴恢复；保留特写单拍声与背景音乐。预览和导出共用最终时间线，支持裁剪、排除、倒放、往返和重复。
- 新增「文件 → 导入视频（实验）…」，可设置片段和采样帧率，再复用鸟眼/鸟头或飞机机头识别、轨迹与自动裁切。单独拖入视频也进入该面板。
- 支持导入静态 Gyroflow OpenCV 鱼眼/常规镜头 JSON，在识别前校正。新缓存按原文件、片段、帧率和配置区分；取消和失败清理未完成缓存。
- 每次上限 120 秒 / 3600 帧，暂限 8 位 SDR 帧缓存；没有实现陀螺仪同步、滚动快门校正或动态镜头补偿。适用范围与操作见[视频导入与镜头配置](视频导入与镜头配置.md)。

## 1.4.3 测试版 · 2026-10-28

[下载 v1.4.3-beta.1](https://github.com/cyandee/BirdLock/releases/tag/v1.4.3-beta.1)，Mac 和 Windows 的软件版本都是 1.4.3。这次主要处理大家反馈的导出问题，包含此前 1.4.1、1.4.2 本地测试的修复。

- 修复 Windows 在界面上更换编码、质量等选项后，无法导出且要重启才能恢复的问题。
- 改善取消导出后的恢复：打断视频写入和编码收尾，等待子进程退出；关闭导出窗口也会取消当前任务。临时文件短暂被占用时重试清理，保留原有同名视频。
- 修复图片解码异常时其他渲染线程一直等待的问题，以及硬件编码失败后转软件编码的一处错误；复用编码器检测结果，减少重复探测。
- 高分辨率色彩转换改用小查表，减少临时数组，针对部分用户遇到的索引越界报错做了修复。
- Mac 光流补帧修正帧提交方式，放入独立辅助进程。不可用、底层异常或长时间无响应时，明确提示并回退到帧混合。
- Mac 长序列按处理量回收光流进程并清理渲染缓存，降低内存累积。输出尺寸、帧率、补帧数量和时间线不变，回收可能增加导出时间。
- 两端加入「帮助 → 导出诊断日志」，收集运行记录、系统信息和错误堆栈，默认隐藏用户目录，不包含原照片、音频或设置文件。Mac 还会收集最近的 BirdLock 系统崩溃报告。
- 优化飞机跟踪中的局部图像转换、大组照片缓存检查，以及多核心 CPU 上的机头推理线程使用。不更换鸟类模型、机头权重或识别阈值。
- 增加鸟头、鸟眼分析阶段的高清读取、预处理、推理排队和模型运行耗时记录；识鸟与鸟头分别显示运行设备，修正回退 CPU 后仍显示显卡的问题。

已做本地回归和横、竖 2K / 30 fps 长序列压力测试。原 M1 Max/macOS 15.5 和 Windows 显卡设备仍需用原片复测；鸟类首次分析暂时没有明确的整体提速结论。完整范围见[测试记录](整批功能验收清单.md)。

## 1.4.0 测试版 · 2026-10-19

[下载 v1.4.0-beta.1](https://github.com/cyandee/BirdLock/releases/tag/v1.4.0-beta.1)，Mac 和 Windows 的软件版本都是 1.4.0。

这次主要调整了多组连拍的顺序、特写快门声和相机音效菜单。

- 多组连拍合并后可以上移、下移，调整播放顺序。修正、排除标记和特写跟着照片走，每组仍按自己的拍摄顺序和连拍速度播放。
- 特写开始时可以播放一次单张快门声，支持开关和独立音量。延长照片停留时间不会让声音一直循环；旧特写仍保持原来的无声设置。
- 内置音效换成了完整录音，先选相机再选档位。A1 II 有 5 / 10 / 15 / 20 / 30 fps，A9 III 有 60 / 120 fps，A7 V 有 Hi+ 30 / Mid 15 fps，Z8 为 20 fps。A7R VI 暂时标为「原录音」。
- 修复 Windows 部分界面控件更新和短音频混音问题；调整画面设置时，尽量避免不必要的音乐重载。
- Mac 打包时增加镜像、应用签名和复制安装后的完整性检查，下载页附 SHA256 校验文件。
- 帮助菜单加入「请作者喝杯咖啡」。反馈统一使用邮箱 cyanodee@gmail.com。

这一版仍是测试版。Mac 尚未做 Apple 公证；飞机模式在复杂角度下还可能找错机头。如果遇到问题，欢迎把操作步骤和报错发给我。
