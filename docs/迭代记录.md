# 更新记录

## 1.4.0 测试版 · 2026-10-19

[下载 v1.4.0-beta.1](https://github.com/cyandee/BirdLock/releases/tag/v1.4.0-beta.1)，Mac 和 Windows 的软件版本都是 1.4.0。

这次主要调整了多组连拍的顺序、特写快门声和相机音效菜单。

- 多组连拍合并后可以上移、下移，调整播放顺序。修正、排除标记和特写跟着照片走，每组仍按自己的拍摄顺序和连拍速度播放。
- 特写开始时可以播放一次单张快门声，支持开关和独立音量。延长照片停留时间不会让声音一直循环；旧特写仍保持原来的无声设置。
- 内置音效换成了完整录音，先选相机再选档位。A1 II 有 5 / 10 / 15 / 20 / 30 fps，A9 III 有 60 / 120 fps，A7 V 有 Hi+ 30 / Mid 15 fps，Z8 为 20 fps。A7R VI 暂时标为「原录音」。
- 修复 Windows 部分界面控件更新和短音频混音问题；调整画面设置时，尽量避免不必要的音乐重载。
- Mac 打包时增加镜像、应用签名和复制安装后的完整性检查，下载页附 SHA256 校验文件。
- 帮助菜单加入「请作者喝杯咖啡」。反馈统一使用邮箱 cyanodee@gmail.com。

这一版仍是测试版。Mac 尚未做 Apple 公证；飞机模式在复杂角度下还可能找错机头。如果遇到问题，欢迎把操作步骤和报错发给我。

## 1.3.0

- 照片导入时可归成一组，或按拍摄间隔分组；多组可以接成一个视频，也能切换查看单组。
- 加入关键帧特写，可以替换一段照片的播放时间，调整放大、构图和动态框。
- 加入背景音乐节拍、高潮位置和画面候选，方便手动卡点。
- 加入飞机试验模式：识别机身、定位和跟踪机头，支持手动修正。鸟类与飞机分别保存设置和识别缓存。
- 修复 Windows 短音频播放结束后，混音延迟或静音不正常的问题。

## 1.2.0

- 鸟眼、鸟头、鸟身可以分别改颜色，鸟身框大小可以单独调。
- 快门闪烁边框支持大小、颜色和最高 120 次/秒。
- 加入多条音轨，快门声和背景音乐可以同时使用，各自调整音量、起点和淡入淡出。
- 早期的索尼音效档位已在 1.4 换成新的完整录音，当前选择见[音效说明](../SharedResources/Audio/README.md)。

## 1.1.0

- 保留此前 Windows 的导入、界面、线程和编码修复，继续处理退出时的回调和编辑保存问题。
