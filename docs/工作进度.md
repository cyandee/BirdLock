# BirdLock 项目近况

更新于2026-11-04。Mac与Windows共用VERSION 1.10.0；本次发布固定选眼、自定义目标跟踪和Windows飞机机头DirectML后端。

- 任意清晰参考帧固定一只鸟眼，可恢复自动、撤销、保存工程。
- 框选稳定区域并独立点选锁定点，向前/向后跟踪，失锁处补充关键帧，不增加模型权重。
- 飞机机头遵循设备选择，优先DirectML，失败回退CPU，并记录实际执行分配与耗时。
- 本地Swift96、Python158、打包工具28项通过；两端工程互开与导出已验证。
- RTX3080实际提速及真实动物/昆虫复杂素材仍待实机复测。Windows本轮由用户在实体电脑验收，本机Qt/PYZ测试不等于Windows运行验证。
