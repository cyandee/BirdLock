# 项目近况

更新于 2026-10-30。

## 1.5.0 测试版与更新源

这次给两端加入软件内更新，私钥只留在本机，安装包和更新清单都做签名校验。Mac 使用 Sparkle 增量更新，Windows 用独立更新器，支持文件级增量、续传、完整包兜底和启动失败回退。已有软件需要先手动安装一次带更新器的版本。

目前已做隔离安装与重启测试，并生成双平台本地候选包。Swift 54 项、Windows 94 项、分发脚本 19 项，以及原生更新器 42 项断言和 7 项安装进程测试通过。Mac 另测增量成功、损坏增量转完整包、篡改清单拒绝；使用独立验证应用和模拟网络，不代替完整 BirdLock 的公网升级测试。

1.5.0 双平台安装包、源码及签名更新文件已发布，线上更新清单已开放。旧版需先手动安装一次；当前已装 1.5.0 时会显示暂无更新。新版本同时保留下方的 Mac 光流闪烁修复。说明与发布准备见[自动更新](自动更新.md)。

## 1.4.4 本地修复测试

Mac AI 光流的结果读回改用与输入一致的显式色彩空间，修复原始帧与补帧明暗交替。静止灰阶、彩色色块和运动前景的背景一致性已加入回归；Swift 54 项通过，同一组 53 张原片的 HEVC、H.264 和 ProRes 导出完成对照。

这项修复已随 1.5.0 源码同步，修复现已随 1.5.0 安装包发布。使用旧包遇到同样情况，可先改用重复帧。

## 当前版本

Mac 与 Windows 源码版本统一为 1.5.0，文档同步更新。包含自动更新实现、Mac 光流闪烁修复，以及此前 Windows 导出恢复、光流内存回收和双平台诊断日志。变化见[更新记录](迭代记录.md)。

[1.5.0 测试版](https://github.com/cyandee/BirdLock/releases/tag/v1.5.0-beta.1)提供 Mac、Windows、对应源码和 SHA256 校验文件。安装包使用本地已测版本，旧版本保留。

## 1.4.3 已做的测试

- Swift 52 项、Mac/Windows Python 各 89 项通过。
- Windows 成品实际操作 H.264、HEVC、两种 ProRes 和质量选项，测试取消、重试、换组、GIF、图片序列和短音频。
- Mac 测试辅助进程异常与超时保护、正常光流视频、日志 ZIP，以及镜像和复制安装后的签名完整性。
- 长序列用 12 张样例循环组成 600 条源帧，源 20 fps、输出 30 fps，横、竖 2K 都完整导出。受控样例的内存峰值明显下降，但测试设备与原 M1 Max 不同，仍需原片复测。

具体条件、内存数据和画质限制见[测试记录](整批功能验收清单.md)。

## 接下来需要的反馈

- **Mac 光流**：请原 M1 Max/macOS 15.5 使用相同照片和设置，分别开关光流导出；异常时保留完整系统崩溃报告。
- **Windows 导出**：请原显卡设备在同一次运行里切换编码、修改质量，并测试取消后重新导出。
- **照片分析速度**：鸟类首次分析暂时没有明确的整体提速结论，新的阶段耗时和运行设备日志可以帮助继续定位。
- **设备兼容**：实体 Intel Mac、不同 Windows 显卡、低内存电脑和真实飞机连拍还需要补测。
- **安装与分发**：Mac 尚未做 Apple 公证。本次[云端构建](https://github.com/cyandee/BirdLock/actions/runs/40693720238)因 Mac 编译器兼容和 Windows 许可文件校验失败，没有生成新的双平台包；发布使用本地已测包。固定正式版下载入口后续再整理。

遇到问题可从「帮助 → 导出诊断日志」保存 ZIP，附上版本、系统、导出设置和操作步骤发给我：[cyanodee@gmail.com](mailto:cyanodee@gmail.com)。日志不包含原照片或设置，默认隐藏用户目录，发送前可以解压查看。

照片分析和合成都在本地完成。手动修正、排除和特写暂存在缓存里，清理前请保存需要的成片。
