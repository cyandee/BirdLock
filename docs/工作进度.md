# 项目近况



更新于 2026-10-19。

## 现在可以下载的版本



[1.4.0 测试版](https://github.com/cyandee/BirdLock/releases/tag/v1.4.0-beta.1)已经放上 GitHub，Mac、Windows、源码和校验文件都在同一个下载页，旧版本也保留着。

这一版补了多组连拍排序、特写单张快门声，整理了相机音效菜单。完整变化见[更新记录](迭代记录.md)。

## 还在处理什么



- **Mac 安装**：目前没有 Apple 公证，首次打开可能被系统拦截。此前收到的 UTF-8 启动报错还没在测试环境中复现，遇到同样问题请把系统、芯片和报错发给我。
- **飞机识别**：复杂角度、小目标和遮挡时可能找错机头，需要更多真实连拍测试。目前可以逐帧修正。
- **设备兼容**：实体 Intel Mac、不同 Windows 显卡和低内存电脑还需要补测。
- **自动打包**：这次标签触发的云端构建失败，Mac 是 SDK 接口兼容问题，Windows 是构建脚本中文输出的编码问题。下载页用的是本地已经测试并重新核对过的包，云端失败没有替换它们。详情见[构建说明](构建与发布.md)。
- 固定的正式版下载入口，等正式版上线时再整理。

照片分析和合成都在本地完成。手动修正、排除和特写暂存在缓存里，清理前请保存需要的成片。
