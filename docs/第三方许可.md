## 第三方组件

**YOLO11m 鸟类检测模型**
- 来源：Ultralytics（https://github.com/ultralytics/ultralytics）
- 许可：AGPL-3.0
- 训练数据：COCO 数据集（标注采用 CC BY 4.0）

**eye-pose-v0 鸟头 / 鸟眼关键点模型**
- 来源：https://huggingface.co/synthet/eye-pose-v0
- 基于 Ultralytics YOLO11n-pose（AGPL-3.0）微调
- 训练数据：CUB-200-2011（Caltech-UCSD Birds），图片来自 Flickr，通常仅供非商业研究使用

**Apple 系统框架**
- Core ML、Vision、Core Image、Metal、AVFoundation、VideoToolbox 等，随 macOS 提供，依据 Apple 的软件许可协议使用。

**飞机试验模式组件（1.4源码）**
- Grounding DINO tiny：IDEA-Research；ONNX转换来自ONNX Community，两者模型页标注Apache-2.0。固定来源、版本、校验与限制见源代码 `SharedResources/AircraftModels/manifest.json` 和同目录README。
- ONNX Runtime及Swift绑定：Microsoft Corporation，MIT；Mac独立运行库固定Swift包1.24.2对应源码提交。声明文本保存在源代码 `SharedResources/AircraftModels/Licenses/`。1.4源码已接入试验飞机模式；保留官方1.24.2完整第三方声明ONNXRuntime-ThirdPartyNotices.txt，构建时与模型和MIT/Apache文本一起复制。本地双平台成品完整性已验证，云端构建和后续分发仍须检查各自成品。
