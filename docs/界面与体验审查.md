# 1.8.1 界面与主要流程体验审查

本轮从已交付1.8.0、本地Git干净基线05bb7fe继续。检查双端源码及主要界面；Mac原生控件和Qt在本机运行验证，Windows实体运行由用户测试。公开版本仍为1.5.0。

| 流程 | 审查及已调整内容 | 验证 |
|---|---|---|
| 素材入口 | 空白页同时提示照片与视频；保留鸟类/飞机选择及实验范围 | 双端源码核对，Qt主窗口 |
| 视频参数 | 导入前给出实际起止、帧数及帧率；与解码器共用同一校验，先阻止越界/超量参数 | Swift/Python边界回归、实际C0320控件 |
| 镜头配置 | 一个框内完成搜索与选择；清除、回车、Esc、无结果、外部配置都保留明确状态；未确认搜索词不能开始导入 | 原生AppKit控件、Qt键盘/弹出列表及实际XML |
| 异步识别 | 自动识别身份可更新展示，但不覆盖用户已操作的镜头选择；失败配置不替换原有有效选择 | Qt迟到回调与不匹配配置逻辑检查，原生状态门控 |
| 构图与防抖 | 锁定大小时固定裁切的实际强制状态在开关上体现；无陀螺仪或纯图像方法时禁用同步/微调 | 实际36帧Qt工程和原生源码/构建 |
| 时间线与声音 | 视频原声名称一致，保留音量/静音/特写混音及剪辑跟随；不向用户展示缓存WAV文件名 | 实际原声导入导出及既有音频回归 |
| 预览与设置 | 构图、画面、输出三页的切换、长标签与侧栏布局；保留原图修正和预览入口 | Qt 1080×760及1600×1000窗口，原生导入截图 |
| 导出 | 视频默认使用原视频名/所在目录，飞机使用机头锁定后缀；无画面时禁用导出，保留提示；取消时明确等待状态 | 原片目录/名称检查、实际MP4及取消核心回归 |
| 反馈与帮助 | 禁用主按钮外观与状态一致；配置查找/标定说明按需展开；保留帮助、协议和更新入口 | Qt截图及源码核对 |

本轮Swift83项、Python136项（含8项新导入体验回归）及打包工具检查。Qt真实素材36帧原声MP4、搜索选择、XML、导出默认目录和大小锁定状态通过；原生单框搜索、回车、Esc、清除与真实视频导入面板通过。现有照片分组、编辑缓存、特写/音频、增稳和导出回归继续覆盖原有行为。

这不是所有相机、素材或物理显卡的穷举验收；Windows本轮未运行，Intel实机、高DPI不同缩放/多显示器及屏幕阅读器仍需相应设备验证。1.8的算法、383份镜头数据及原片保持不变；不承诺滚动快门、动态镜头或HDR。最终包与源代码核验见工作进度末尾。

单框使用系统的[AppKit NSComboBox](https://developer.apple.com/documentation/appkit/nscombobox)与[Qt QCompleter](https://doc.qt.io/qt-6/qcompleter.html)，没有增加新的第三方依赖。
