# BirdLock 鸟眼锁定

BirdLock 是一个把飞鸟连拍照片做成视频的小工具。导入照片后，它会识别鸟眼、对齐画面，让鸟头的位置尽量保持稳定，留下翅膀扇动的过程。

我希望做这类视频能简单一点：不用逐张挪照片，也能调整构图、加上对焦框和快门声，再配一段音乐。现在有 macOS 和 Windows 两个版本，免费使用，开源代码也在这里。

当前版本为 **1.10.0**（Mac / Windows）：整组固定选眼、自定义目标框选跟踪，以及 Windows 飞机机头 DirectML 后端与诊断。操作与限制见[新功能指南](docs/自定义目标与固定选眼.md)及[1.10更新说明](docs/更新说明-1.10.0.md)。RTX 3080 实际提速和复杂动物/昆虫素材仍需实机复测。

此前1.9.0新增视频导入、原声与增稳、陀螺仪同步、383份可搜索镜头配置、强力裁切、主体大小稳定、工程文件和缓存管理；详见[1.5→1.9累计更新说明](docs/更新说明-1.9.0.md)。升级后首次打开显示累计说明，也可在帮助菜单再次查看。

视频入口保留 SDR、每次 120 秒 / 3600 帧的实验范围。陀螺仪路径需要真实运动采样，Sony XML 身份信息本身不是标定或陀螺仪；没有采样时使用图像防抖。Mac 原生及 Python 核心已做本地验证；本次 Windows 运行验证由用户在实体电脑完成，不承诺完整 Gyroflow、动态镜头、滚动快门或 HDR 工作流。

## 怎么用

1. 导入一组连拍照片，等软件识别鸟眼。
2. 选一个构图，调整画面比例、大小和播放速度。
3. 按空格预览，需要的话修正个别照片的鸟眼位置。
4. 加上对焦框、快门声或背景音乐，导出视频。

支持 JPG、HEIF / HEIC、PNG 和 TIFF。RAW 请先转成 JPG 或 HEIF。照片处理都在自己的电脑上完成，不上传照片。

详细操作：[macOS 使用说明](docs/使用说明.md) · [Windows 使用说明](docs/windows/使用说明.md)

## 这次更新了什么

1.10.0 新增：

- **整组固定鸟眼**：点选要跟随的眼睛，从任意一张清晰照片应用到当前连续组。固定模式保持同一只眼，短暂遮挡显示推算，长时间缺少可靠观测时提示未跟踪。
- **自定义目标跟踪**：拖出稳定区域后在框内点选锁定点，从参考帧向前、向后跟踪本组；失锁处可补选参考关键帧，结果沿用构图、预览、导出与工程流程。
- **Windows 飞机机头显卡后端**：机头改为遵循设备设置，优先使用 DirectML，失败回退 CPU，日志记录加载、推理和回退情况。

此前版本加入的视频导入与增稳、383 份镜头配置、工程保存与缓存管理继续保留。完整说明见[1.10 更新说明](docs/更新说明-1.10.0.md)，版本历史见[迭代记录](docs/迭代记录.md)。Windows 飞机显卡的实际提速仍需 RTX 3080 等实体设备复测，状态见[测试记录](docs/整批功能验收清单.md)。

## 连拍、特写和音效

**多组连拍可以接在一起。** 中途松开快门，再拍的一组也能接着用。导入时可以选择归成一组或按间隔分组，合并后用上移、下移调整播放顺序。手动修正、排除的照片和特写会一起跟着移动。

**特写可以停得更久。** 选一张照片放大，调整停留时间和构图，再加一个动态框。特写开始时可以响一次单张快门声，音量单独调，也可以关掉。

**快门音效按相机和档位来选。** 这次整理了完整录音，先选相机，再选 fps；也可以同时放快门声和背景音乐。

| 相机 | 内置录音 |
|---|---|
| 索尼 A1 II（A1M2） | 5 / 10 / 15 / 20 / 30 fps |
| 索尼 A9 III（A93） | 60 / 120 fps |
| 索尼 A7 V（A7M5） | Hi+ 30 fps / Mid 15 fps |
| 索尼 A7R VI（A7R6） | 原录音，帧率暂未确认 |
| 尼康 Z8 | 20 fps |

这些档位播放各自的录音，不靠变速凑帧率。特写用的单张快门另选了一个 CC0 素材，来源见[音效说明](SharedResources/Audio/README.md)。

## 还可以做什么

- 鸟眼、鸟头、鸟身框分别开关和配色，鸟身框可以调大小，包含识别到的展开翅膀。
- 模拟拍摄时的闪烁边框，大小、颜色、频率都能调。最高 120 次/秒，实际看起来怎样还受视频帧率影响。
- 调整缩放、位置、旋转和跟随方式，加图片或文字水印。
- 添加多条音轨，分别调音量、起点、循环和淡入淡出。音乐节拍、高潮位置会给出参考，选好后再试听。
- 导出 H.264、HEVC、ProRes 视频，也可以导出 GIF 或对齐后的图片。
- 试用飞机模式，识别机头和机身，沿用对焦框和快门模拟。

飞机模式还在打磨，倒置、小目标和遮挡时可能找错机头，使用前请逐帧看一下，必要时手动修正。音乐卡点也只是辅助，最后还是以耳朵听到的效果为准。

可保存独立 `.birdlock` 工程继续编辑；工程引用原片与外部音频，请同时保留素材。使用缓存管理清理可重建的过程文件。实体 Intel Mac、Windows 不同显卡和低内存电脑还需要更多反馈。

## 源码和文档

macOS 使用 SwiftUI / Core ML，Windows 使用 Python / Qt / ONNX Runtime。版本号统一放在 [VERSION](VERSION)。

```zsh
zsh scripts/build_app.sh   # 只构建 dist/BirdLock.app
zsh scripts/make_dmg.sh    # 构建通用版 app 并打成 dist/BirdLock-<版本>.dmg
```

Windows 构建方法见 [windows/README.md](windows/README.md)。飞机模型约 204 MB，构建脚本会按固定版本和 SHA256 下载；安装包已经包含模型，使用时不用另外下载。
