# BirdLock 鸟眼锁定

BirdLock 是一个把飞鸟连拍照片做成视频的小工具。导入照片后，它会识别鸟眼、对齐画面，让鸟头的位置尽量保持稳定，留下翅膀扇动的过程。

我希望做这类视频能简单一点：不用逐张挪照片，也能调整构图、加上对焦框和快门声，再配一段音乐。现在有 macOS 和 Windows 两个版本，免费使用，开源代码也在这里。

## 怎么用

1. 导入一组连拍照片，等软件识别鸟眼。
2. 选一个构图，调整画面比例、大小和播放速度。
3. 按空格预览，需要的话修正个别照片的鸟眼位置。
4. 加上对焦框、快门声或背景音乐，导出视频。

支持 JPG、HEIF / HEIC、PNG 和 TIFF。RAW 请先转成 JPG 或 HEIF。照片处理都在自己的电脑上完成，不上传照片。

详细操作：[macOS 使用说明](docs/使用说明.md) · [Windows 使用说明](docs/windows/使用说明.md)

## 这次更新了什么

1.4.3 主要处理大家反馈的导出问题，也包含此前 1.4.1、1.4.2 本地测试的修复：

- **Windows 导出恢复**：修复切换编码或画质后不能导出、取消后无法再次导出的问题；改善编码进程退出和临时文件清理。
- **Mac 光流保护**：光流补帧改由独立辅助进程处理，异常或长时间无响应时提示并回退到帧混合。长序列按处理量回收进程和渲染缓存，降低内存累积，可能增加导出时间。
- **高分辨率处理**：调整色彩转换，减少大块临时数组，针对部分用户遇到的索引越界报错做了修复。
- **诊断日志**：两端都可以在「帮助 → 导出诊断日志」保存 ZIP，闪退后重新打开也可以导出。日志不包含原照片或设置，默认隐藏用户目录。
- **分析排查**：优化飞机跟踪和大组缓存检查，补充鸟头、鸟眼分析各阶段的耗时和实际运行设备记录。鸟类首次分析暂时没有明确的整体提速结论。

本地回归和长序列压力测试已完成，原 M1 Max/macOS 15.5 及 Windows 显卡设备仍需要用原片复测。具体范围见[更新记录](docs/迭代记录.md)和[测试记录](docs/整批功能验收清单.md)。

## 连拍、特写和音效

**多组连拍可以接在一起。** 中途松开快门，再拍的一组也能接着用。导入时可以选择归成一组或按间隔分组，合并后用上移、下移调整播放顺序。手动修正、排除的照片和特写会一起跟着移动。

**特写可以停得更久。** 选一张照片放大，调整停留时间和构图，再加一个动态框。特写开始时可以响一次单张快门声，音量单独调，也可以关掉。

**快门音效按相机和档位来选。** 这次整理了完整录音，先选相机，再选 fps；也可以同时放快门声和背景音乐。

| 相机 | 内置录音 |
|---|---|
| 索尼 A1 II（A1M2） | 5 / 10 / 15 / 20 / 30 fps |
| 索尼 A9 III（A93） | 60 / 120 fps |
| 索尼 A7 V（A7M5） | Hi+ 30 fps / Mid 15 fps |
| 索尼 A7R VI（A7R6） | 原录音，帧率暂未确认 |
| 尼康 Z8 | 20 fps |

这些档位播放各自的录音，不靠变速凑帧率。特写用的单张快门另选了一个 CC0 素材，来源见[音效说明](SharedResources/Audio/README.md)。

## 还可以做什么

- 鸟眼、鸟头、鸟身框分别开关和配色，鸟身框可以调大小，包含识别到的展开翅膀。
- 模拟拍摄时的闪烁边框，大小、颜色、频率都能调。最高 120 次/秒，实际看起来怎样还受视频帧率影响。
- 调整缩放、位置、旋转和跟随方式，加图片或文字水印。
- 添加多条音轨，分别调音量、起点、循环和淡入淡出。音乐节拍、高潮位置会给出参考，选好后再试听。
- 导出 H.264、HEVC、ProRes 视频，也可以导出 GIF 或对齐后的图片。
- 试用飞机模式，识别机头和机身，沿用对焦框和快门模拟。

飞机模式还在打磨，倒置、小目标和遮挡时可能找错机头，使用前请逐帧看一下，必要时手动修正。音乐卡点也只是辅助，最后还是以耳朵听到的效果为准。

目前还没有独立的工程文件，手动修正和特写保存在缓存里，清缓存前请先保存需要的成片。实体 Intel Mac、Windows 不同显卡和低内存电脑还需要更多反馈。
